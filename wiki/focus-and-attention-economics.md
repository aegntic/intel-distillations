# Focus and Attention Economics

Human attention, not tokens, is the binding constraint on agent leverage: cognitive bandwidth does not parallelize, and parallel agent sessions are what force the switching [f02 1:42]. Where [context-discipline](context-discipline.md) covers token economics, this file covers attention economics. Four of ten sources in the 2026-10-27 corpus converge here. Related: [context-discipline](context-discipline.md), [sub-agents-and-parallelism](sub-agents-and-parallelism.md), [definition-of-done](definition-of-done.md).

## Synthesis

Attention is the scarce input. Newport's scarcity framing opens the case [f02 1:31]; one creator reports ~100x more context switches than 5 years ago [unverified], and the named failure mode is guilt while waiting on an agent, which spawns yet another session [f02 1:42, 0:40, 3:05].

The operating fix is cadence, not willpower: batch check-ins about once a day per stream, with recovered attention reinvested into harness autonomy (rules, skills, codified validation) so a stream can run a day or more unattended [f02 13:10, 9:20, 10:13]. Cole Medin predicts near-instant model responses (hundreds of tokens per second) will collapse working style into one primary orchestrating session instead of many parallel conversations [f02 14:05, 13:56].

The macro version is an audit, not a vibe: Galloway's intervention opens with a screen-time audit (10-50 recoverable hours per week in Twitter, TikTok, porn, trading apps) and names frictionless digital substitutes, not sentience, as the gravest near-term AI risk [f07 35:54, 16:53]. News-cutting is attention defense: keep one or two causes you can influence and cut the rest [f04 36:13]. Deep-focus pressure valves like deliberate games protect the bandwidth that remains [f02 8:03].

The pressure law closes the loop: capability gains raise output expectations in step, so recovered time is never a windfall [f02 2:59]. Sustained focus is underweighted in AI conversations: with identical tools, one person starts 15 projects in a month and quits each when work gets awkward, the other stays on one customer problem [f03 11:44, 9:39].

## Key claims

- Cognitive bandwidth does not parallelize; parallel sessions force the switching [f02 1:42].

- One primary orchestrating session is the predicted steady state [f02 14:05, 13:56].
- A screen-time audit recovers 10-50 hours per week [f07 35:54].
- Pressure law: capability gains raise output expectations in step [f02 2:59].

## Apply to aegntic

- Set completion pings plus one fixed daily review slot for the cron fleet; no mid-day peeking [f02 13:10].
- Run a screen-time audit and reallocate recovered hours to harness rules and skills, not more sessions [f07 35:54].
- Anti-goal for the council checklist: AI can make distraction look productive (many prototypes and three plans by 5pm, none far enough to matter) [f03 12:31].
